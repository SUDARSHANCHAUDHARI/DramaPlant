# Changelog

All notable user-facing changes to DramaPlant are recorded here.

## [1.0.0] - 2026-07-19

### Added

- Interactive pointer, touch, and keyboard watering-can controls
- Ten shuffled dramatic plant reactions with visible mood and history
- Water particles and generated Web Audio with a persistent sound toggle
- Six-attempt trust progression into a healthy flowering plant
- Responsive layout, live announcements, focus states, and reduced-motion behavior
- GitHub Pages metadata, production verification, security guidance, and repository documentation
